# IR Drill v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the five v2 upgrade phases from the spec: storage v2, UI/theme polish, overlay controls and a rules sheet, filters plus adaptive drill plus stats, deflected/interactive CDI plus free-input answers, and an offline PWA.

**Architecture:** Same as v1: plain ES modules, no build step, no dependencies. `rules.js`, `generator.js`, `store.js` and `instruments/*` stay pure and are tested with `node --test`; `app.js` + `index.html` are the only DOM code. Every task leaves `npm test` green and the app working.

**Tech Stack:** Vanilla JS (ES2022 modules), inline SVG, Node ≥ 20 (`node:test`), static hosting (GitHub Pages).

**Spec:** `docs/superpowers/specs/2026-11-27-ir-drill-v2-design.md`
**Branch:** `feat/v2` (never commit to `master`).

## Smaller decisions taken in this plan (flag in review if you disagree)

- `load()` reads `basicir.v2`; if that is missing **or unparseable / wrong version**, it migrates `basicir.v1`; otherwise defaults.
- The v1-compatible draw order is kept: with default filters, `makeScenario` consumes the RNG exactly as v1 did (so old seeds give the same scenarios). The canonical nav order is therefore `['NDB', 'VOR']`.
- `setupError` moves from `app.js` to `generator.js` (pure, testable).
- `emphasisParts` (option-label bolding) is a pure helper in `generator.js`.
- Overlay / Frame toggles (§2.1) appear only when `display !== 'numbers'` (numbers mode already shows the north-up rose). Frame is disabled while Overlay is Off.
- The Rules sheet's holding diagrams are generated by a pure `sectorDiagram(turn)` (same drawing code as the overlay) instead of hand-written SVG.
- `cdiReading` returns `{ flag: 'OFF', deflection: 0 }` within ±1° of abeam.
- `weakest category` = the seen statKey with the highest `statWeight` (same notion as the adaptive drill).
- PWA icon is a static `icon.svg` file (manifest icons cannot reliably be data URIs).
- §5.2 (deferred syllabus) needs no code: the existing `throw` in `interception()` for inbound Δ > 70° is the hook.

## Domain glossary for the implementer

- *Radial* / *QDR* = bearing FROM the station. *QDM* = bearing TO the station = radial + 180.
- *STD holding* = right turns; *Non-STD* = left turns. *Track to fix* = course flown to the holding fix.
- *OBS* = selected course on a VOR (CDI or HSI). *FROM flag*: you are on radial ≈ OBS. *TO flag*: QDM ≈ OBS.
- All angles are integers in [0, 360). Use `norm()` from `rules.js` for every result.

## Project rules the implementer must follow

These come from `.claude/skills/*/SKILL.md` in the repo. Read the one named in a task before starting it.

- **Mistake labels never contain a comma** (`buildQuestion` treats a comma as a multi-mistake option).
- Scenarios stay plain JSON; `buildQuestion(s, rng)` depends only on `s` and `rng` (review mode replays stored scenarios).
- Overlay lines are drawn in the card's own frame with `rotate(bearing 100 100)`; every overlay element carries `data-role` (+ `data-bearing` where it is a line).
- The DI+CDI flag box sits below the dot row (rect x=110 y=116 34×18) and is drawn before the needle.
- HSI and DI+CDI never show an NDB; holding instruments show `hdg === trk`.
- Never use `innerHTML` with user-typed text. SVG strings from our own pure renderers are fine.

```js
// localStorage persistence. Every access is guarded: the app must work without storage.
const KEY = 'basicir.v2';
const V1_KEY = 'basicir.v1';
const HISTORY_MAX = 30;

// Allowed values per filter, in the order the generator draws from them (keeps v1 seeds stable).
export const FILTER_VALUES = {
  bands: ['correction', '45', '90/45', 'overstation'],
  dirs: ['inbound', 'outbound'],
  phrasings: ['radial', 'q'],
  turns: ['std', 'nonstd'],
  navs: ['NDB', 'VOR'],
};

export const defaults = () => ({
  version: 2,
  settings: {
    types: ['intercept', 'hold'],
    display: 'numbers', // 'numbers' | 'instruments' | 'mixed'
    instruments: ['rmi'], // subset of ['rmi', 'hsi', 'dicdi']
    timer: 45, // 0..600
    length: 20, // 0 | 10 | 20
    theme: 'system', // 'system' | 'light' | 'dark'
    answerMode: 'mc', // 'mc' | 'input'
    cdiMode: 'centered', // 'centered' | 'deflected' | 'interactive'
    adaptive: false,
    filters: {
      ...Object.fromEntries(Object.entries(FILTER_VALUES).map(([k, v]) => [k, [...v]])),
      boundaryFocus: false,
    },
  },
  stats: {}, // statKey → { correct, total, ms }
  mistakes: [], // scenarios
  history: [], // last 30 sessions: { at, right, total, avgMs, review }
});

const storageOr = (storage) => storage ?? globalThis.localStorage;
const isObj = (v) => v !== null && typeof v === 'object' && !Array.isArray(v);
const oneOf = (v, ok, d) => (ok.includes(v) ? v : d);
const known = (v, ok, d) => (Array.isArray(v) && v.every((x) => typeof x === 'string') ? v.filter((x) => ok.includes(x)) : d);
const bool = (v, d) => (typeof v === 'boolean' ? v : d);

// Any field that fails validation falls back to its default.
function validSettings(s, def) {
  const f = isObj(s.filters) ? s.filters : {};
  const filters = { boundaryFocus: bool(f.boundaryFocus, def.filters.boundaryFocus) };
  for (const [k, ok] of Object.entries(FILTER_VALUES)) filters[k] = known(f[k], ok, def.filters[k]);
  return {
    types: known(s.types, ['intercept', 'hold'], def.types),
    instruments: known(s.instruments, ['rmi', 'hsi', 'dicdi'], def.instruments),
    display: oneOf(s.display, ['numbers', 'instruments', 'mixed'], def.display),
    timer: Number.isFinite(s.timer) && s.timer >= 0 && s.timer <= 600 ? s.timer : def.timer,
    length: oneOf(s.length, [0, 10, 20], def.length),
    theme: oneOf(s.theme, ['system', 'light', 'dark'], def.theme),
    answerMode: oneOf(s.answerMode, ['mc', 'input'], def.answerMode),
    cdiMode: oneOf(s.cdiMode, ['centered', 'deflected', 'interactive'], def.cdiMode),
    adaptive: bool(s.adaptive, def.adaptive),
    filters,
  };
}

const validMistake = (m) => isObj(m) && (m.kind === 'intercept' || m.kind === 'hold') && typeof m.id === 'string';
const validEntry = (h) => isObj(h) && ['at', 'right', 'total', 'avgMs'].every((k) => Number.isFinite(h[k]));

// Guarded end to end: even touching globalThis.localStorage can throw when storage is blocked.
function read(storage, key) {
  try { return JSON.parse(storageOr(storage).getItem(key)); } catch { return null; }
}

// basicir.v2 first; if missing or unusable, migrate basicir.v1; otherwise defaults.
export function load(storage) {
  let d = read(storage, KEY);
  if (!(isObj(d) && d.version === 2)) {
    const old = read(storage, V1_KEY);
    d = isObj(old) && old.version === 1 ? old : null;
  }
  const def = defaults();
  if (!d) return def;
  return {
    version: 2,
    settings: validSettings(isObj(d.settings) ? d.settings : {}, def.settings),
    stats: isObj(d.stats) ? d.stats : def.stats,
    mistakes: Array.isArray(d.mistakes) ? d.mistakes.filter(validMistake) : def.mistakes,
    history: Array.isArray(d.history) ? d.history.filter(validEntry).slice(-HISTORY_MAX) : def.history,
  };
}

export function save(data, storage) {
  try { storageOr(storage).setItem(KEY, JSON.stringify(data)); } catch { /* not persisted */ }
}

// Record one answered question. Returns the updated data (mutates in place).
export function record(data, { statKey, correct, ms, scenario }) {
  const st = (data.stats[statKey] ??= { correct: 0, total: 0, ms: 0 });
  st.total++;
  st.ms += ms;
  if (correct) st.correct++;
  const i = data.mistakes.findIndex((m) => m.id === scenario.id);
  if (!correct && i === -1) data.mistakes.push(scenario);
  if (correct && i !== -1) data.mistakes.splice(i, 1);
  return data;
}

export function recordSession(data, entry) {
  data.history.push(entry);
  if (data.history.length > HISTORY_MAX) data.history.splice(0, data.history.length - HISTORY_MAX);
  return data;
}

export function clearMistakes(data) {
  data.mistakes = [];
  return data;
}

// Clears stats and history; settings and mistakes stay.
export function resetStats(data) {
  data.stats = {};
  data.history = [];
  return data;
}
```

```js
// Option label → [{ text, bold }]: the leading phrase (up to the first comma or bracket) and every
// 3-digit track are bold. The app renders these as DOM nodes, never as HTML.
export function emphasisParts(text) {
  const cut = text.search(/[,(]/);
  const lead = cut === -1 ? text : text.slice(0, cut);
  const rest = cut === -1 ? '' : text.slice(cut);
  const parts = [{ text: lead, bold: true }];
  let last = 0;
  for (const m of rest.matchAll(/\b\d{3}°/g)) {
    if (m.index > last) parts.push({ text: rest.slice(last, m.index), bold: false });
    parts.push({ text: m[0], bold: true });
    last = m.index + m[0].length;
  }
  if (last < rest.length) parts.push({ text: rest.slice(last), bold: false });
  return parts;
}
```

```js
// Stat keys (see buildQuestion's statKey) that the current types and filters can produce.
export function eligibleKeys(settings) {
  const f = filtersOf(settings);
  const keys = settings.types.includes('intercept')
    ? Object.keys(BANDS).filter((b) => f.bands.includes(b) && f.dirs.some((d) => bandsFor(d, [b]).length))
    : [];
  return settings.types.includes('hold') ? [...keys, 'holding'] : keys;
}

// How much to drill a stat key: unseen first, then by error rate and slowness; never below 0.5.
export function statWeight(st) {
  if (!st || !(st.total > 0)) return 3;
  const acc = st.correct / st.total; // 0..1
  const avgSec = st.ms / st.total / 1000;
  const errorTerm = (1 - acc) * 4; // 0..4
  const speedTerm = Math.min(avgSec / 30, 1.5); // 0..1.5
  return 0.5 + errorTerm + speedTerm;
}

export function pickWeighted(rng, keys, stats) {
  const w = keys.map((k) => statWeight(stats[k]));
  let x = rng() * w.reduce((a, b) => a + b, 0);
  for (let i = 0; i < keys.length; i++) if ((x -= w[i]) < 0) return keys[i];
  return keys.at(-1);
}
```

```js
export function historyAverage(history) {
```

```js
// ---------- VOR CDI ----------

// What a CDI/HSI shows for selected course `obs` when you are on radial `P`.
// deflection: signed degrees off course, positive = needle right (fly right). Not clamped; full scale is ±10°.
// Within ±1° of abeam the flag is OFF.
export function cdiReading(obs, P) {
  const fromDiff = sdiff(obs, P);
  if (Math.abs(Math.abs(fromDiff) - 90) <= 1) return { flag: 'OFF', deflection: 0 };
  if (Math.abs(fromDiff) < 90) return { flag: 'FROM', deflection: -fromDiff || 0 }; // || 0: never -0
  return { flag: 'TO', deflection: sdiff(obs, norm(P + 180)) };
}
```

```js
// ---------- free-input grading ----------

// '' / NaN → missing. Otherwise the first matching diagnosis, or null when exact (after norm).
function trackError(got, want, { mirror = null, mirrored, reciprocal }) {
  if (!Number.isFinite(got)) return 'missing track';
  const g = norm(got);
  if (g === want) return null;
  if (mirror !== null && g === norm(2 * mirror - want)) return mirrored;
  if (g === norm(want + 180)) return reciprocal;
  return `track off by ${Math.abs(sdiff(want, g))}°`;
}

// result: interception() or holding() result. Mistake labels never contain a comma.
// Interception input: { type, initial, intercept } — initial only counts for 90/45 and over-station.
// Holding input: { entry, eitherPair, initial } — for special direct `initial` is the outbound track.
export function gradeFreeInput(result, input) {
  const ok = { correct: true, mistake: null };
  const bad = (mistake) => ({ correct: false, mistake });
  if (result.kind === 'intercept') {
    if (input.type !== result.type) return bad('wrong interception type');
    const over = result.type === 'overstation';
    const fields = result.type === '90/45' || over ? ['initial', 'intercept'] : ['intercept'];
    for (const k of fields) {
      const err = trackError(input[k], result[k], {
        mirror: over && k === 'initial' ? null : result.track,
        mirrored: over ? 'over-station interception on the wrong side' : 'wrong side of the radial',
        reciprocal: 'reciprocal (radial ↔ QDM mix-up)',
      });
      if (err) return bad(err);
    }
    return ok;
  }
  if (result.either) {
    if (input.entry === 'either') {
      const pair = input.eitherPair ?? [];
      return pair.length === 2 && result.either.every((e) => pair.includes(e)) ? ok : bad('wrong boundary');
    }
    return bad(result.either.includes(input.entry)
      ? 'inside ±5° of a sector boundary the answer is "Either …" — not a single entry'
      : 'wrong sector');
  }
  if (input.entry === 'either') return bad('not near a sector boundary (±5°)');
  if (input.entry !== result.entry) return bad('wrong sector');
  const want = result.entry === 'special' ? result.outbound : result.initial;
  if (result.entry === 'special' && Number.isFinite(input.initial) && norm(input.initial) === result.trk) {
    return bad('typed the 15 s track instead of the outbound track');
  }
  const err = trackError(input.initial, want, {
    mirror: result.entry === 'teardrop' ? result.outbound : null,
    mirrored: 'teardrop on the wrong side',
    reciprocal: 'reciprocal track (inbound ↔ outbound mix-up)',
  });
  return err ? bad(err) : ok;
}
```

```js
// Network-first so GitHub Pages updates show up immediately; the cache is the offline fallback.
const CACHE = 'basicir-v2-1';
const FILES = ['./', 'index.html', 'app.js', 'rules.js', 'generator.js', 'store.js', 'manifest.json', 'icon.svg', 'instruments/card.js', 'instruments/dicdi.js', 'instruments/hsi.js', 'instruments/index.js', 'instruments/overlay.js', 'instruments/rmi.js'];

self.addEventListener('install', (e) => {
  e.waitUntil(caches.open(CACHE).then((c) => c.addAll(FILES)).then(() => self.skipWaiting()));
});

self.addEventListener('activate', (e) => {
  e.waitUntil(caches.keys()
    .then((keys) => Promise.all(keys.filter((k) => k !== CACHE).map((k) => caches.delete(k))))
    .then(() => self.clients.claim()));
});

self.addEventListener('fetch', (e) => {
  if (e.request.method !== 'GET' || new URL(e.request.url).origin !== location.origin) return;
  // cache: 'no-cache' revalidates with the server, so a stale HTTP-cached module can never be
  // mixed with a fresh app.js (that mismatch breaks the whole page with a missing-export error).
  e.respondWith(fetch(e.request, { cache: 'no-cache' })
    .then((res) => {
      if (res.ok) { const copy = res.clone(); caches.open(CACHE).then((c) => c.put(e.request, copy)); }
      return res;
    })
    .catch(() => caches.match(e.request, { ignoreSearch: true })));
});
```
