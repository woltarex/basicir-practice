# IR Drill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static web app for drilling Basic IR interception and holding-entry questions as multiple choice, in numbers or instrument (RMI/HSI/DI+CDI) mode, with a countdown, worked solutions, stats and a review-mistakes mode.

**Architecture:** Plain ES modules with no build step. `rules.js` is the single source of truth for the answers. `generator.js` turns random scenarios into questions with labelled distractors. The `instruments/` renderers turn scenarios into SVG strings. `store.js` wraps localStorage. `app.js` and `index.html` are the only DOM code. Everything except `app.js` is pure and tested with `node --test`.

**Tech Stack:** Vanilla JS (ES2022 modules), inline SVG, Node ≥ 20 for tests (`node:test`, `node:assert`), no dependencies.

**Spec:** `docs/superpowers/specs/2026-11-25-ir-drill-design.md`

**Deviations from the spec's file list (deliberate):**
- `instruments/card.js` holds the shared compass card, bezel and lubber line.
- `instruments/index.js` holds the `renderInstrument` dispatcher.
- `instrumentState()` lives in `generator.js`, because both the worked steps and the renderers need it.
- `test/store.test.js` is added.

**Domain glossary for the implementer:**
- *Radial* = magnetic bearing FROM the station.
- *QDR* = same as a radial. *QDM* = bearing TO the station (= radial + 180).
- *Inbound* means flying toward the station.
- *STD holding* = right turns; *Non-STD* = left turns.
- *Track to fix* = the course the aircraft flies to reach the holding fix.

All angles are integers in [0, 360). Use `norm()` for every result.

```js
// Pure rule engine. All angles are integer degrees in [0, 360).

export const norm = (x) => ((Math.round(x) % 360) + 360) % 360;

// Signed smallest difference going from `from` to `to`, in (-180, 180].
export function sdiff(from, to) {
  const d = norm(to - from);
  return d > 180 ? d - 360 : d;
}

export const fmt = (x) => String(norm(x)).padStart(3, '0');

// ---------- Interception ----------

export const INTERCEPT_TYPES = ['correction', '45', '90/45', 'overstation'];

export function interceptBand(absDelta) {
  if (absDelta < 15) return 'correction';
  if (absDelta <= 30) return '45';
  if (absDelta <= 70) return '90/45';
  return 'overstation';
}

// radial: required radial FROM the station. dir: 'inbound' | 'outbound'. pos: actual radial.
export function interception({ radial, dir, pos }) {
  const R = norm(radial);
  const P = norm(pos);
  const T = dir === 'inbound' ? norm(R + 180) : R;
  const delta = sdiff(R, P);
  const a = Math.abs(delta);
  const side = Math.sign(delta) || 1; // +1: you are clockwise of R
  // Turn toward the radial: inbound adds, outbound subtracts.
  const k = dir === 'inbound' ? side : -side;
  const type = interceptBand(a);
  const steps = [
    dir === 'inbound'
      ? `Required track = ${fmt(R)} + 180 = ${fmt(T)}° (inbound)`
      : `Required track = radial = ${fmt(T)}° (outbound)`,
    `You are on R-${fmt(P)} → Δ = ${a}° (${side > 0 ? 'clockwise' : 'anticlockwise'} of R-${fmt(R)})`,
  ];

  if (type === 'correction') {
    const angle = Math.min(2 * a, 30);
    const track = norm(T + k * angle);
    steps.push(`Δ < 15° → correction, angle = 2 × ${a} = ${2 * a}°${2 * a > 30 ? ' → capped at 30°' : ''}`);
    steps.push(`Track = ${fmt(T)} ${k > 0 ? '+' : '−'} ${angle} = ${fmt(track)}° (initial = interception)`);
    return { kind: 'intercept', type, initial: track, intercept: track, steps };
  }
  if (type === '45') {
    const track = norm(T + k * 45);
    steps.push(`15° ≤ Δ ≤ 30° → 45° intercept`);
    steps.push(`Track = ${fmt(T)} ${k > 0 ? '+' : '−'} 45 = ${fmt(track)}° (initial = interception)`);
    return { kind: 'intercept', type, initial: track, intercept: track, steps };
  }
  if (type === '90/45') {
    const initial = norm(T + k * 90);
    const intercept = norm(T + k * 45);
    steps.push(`30° < Δ ≤ 70° → 90°/45° intercept`);
    steps.push(`Initial track = ${fmt(T)} ${k > 0 ? '+' : '−'} 90 = ${fmt(initial)}°`);
    steps.push(`Interception track = ${fmt(T)} ${k > 0 ? '+' : '−'} 45 = ${fmt(intercept)}°`);
    return { kind: 'intercept', type, initial, intercept, steps };
  }
  if (dir === 'inbound') throw new Error('Inbound interception with Δ > 70° is out of scope');
  const K = norm(P + 180);
  const s = sdiff(R, K);
  const angle = Math.min(Math.round(Math.abs(s) / 3), 30);
  const intercept = norm(R - (Math.sign(s) || 1) * angle);
  steps.push(`Δ > 70° → track to the station first: QDM ${fmt(K)}°`);
  steps.push(`After passing: TRK difference = ${Math.abs(s)}°, angle = ${Math.abs(s)} / 3 = ${Math.round(Math.abs(s) / 3)}°${Math.round(Math.abs(s) / 3) > 30 ? ' → capped at 30°' : ''}`);
  steps.push(`Interception track = ${fmt(R)} ${s >= 0 ? '−' : '+'} ${angle} = ${fmt(intercept)}°`);
  return { kind: 'intercept', type, initial: K, intercept, steps };
}

export function interceptText({ type, initial, intercept }) {
  if (type === 'correction') return `Correction, initial track = interception track ${fmt(intercept)}°`;
  if (type === '45') return `45°, initial track = interception track ${fmt(intercept)}°`;
  if (type === '90/45') return `90°/45°, initial track ${fmt(initial)}°, interception track ${fmt(intercept)}°`;
  return `Track to station (${fmt(initial)}°), then over-station interception track ${fmt(intercept)}°`;
}
```

Notes:
- `k` encodes the side the aircraft turns to. For inbound targets the track increases when you are clockwise of the radial; for outbound targets it decreases.
- The 30° cap on corrections can't bind while Δ < 15, but it's kept because the rule says so.

```js
// ---------- Holding ----------

export const ENTRIES = ['direct', 'special', 'teardrop', 'parallel'];
const ENTRY_NAME = { direct: 'Direct', special: 'Special direct', teardrop: 'Teardrop', parallel: 'Parallel' };
// Boundaries with a ±5° "either" zone, and the entries on each side.
const EITHER = [
  { at: 110, pair: ['special', 'teardrop'] },
  { at: 180, pair: ['teardrop', 'parallel'] },
  { at: 290, pair: ['parallel', 'direct'] },
];
export const EITHER_PAIRS = EITHER.map((e) => e.pair);

export function holdAngle({ inbound, turn, trk }) {
  return turn === 'std' ? norm(trk - inbound) : norm(inbound - trk);
}

export function sectorOf(d) {
  if (d < 70 || d > 290) return 'direct';
  if (d < 110) return 'special';
  if (d < 180) return 'teardrop';
  return 'parallel';
}

// Initial track (or heading for special) of a given entry.
export function entryInitial(entry, { inbound, turn, trk }) {
  const O = norm(inbound + 180);
  if (entry === 'teardrop') return norm(turn === 'std' ? O - 30 : O + 30);
  if (entry === 'special') return norm(trk);
  return O;
}

// inbound: inbound track. turn: 'std' (right) | 'nonstd' (left). trk: aircraft track to the fix.
export function holding({ inbound, turn, trk }) {
  const I = norm(inbound);
  const O = norm(I + 180);
  const d = holdAngle({ inbound: I, turn, trk });
  const entry = sectorOf(d);
  const steps = [
    `${turn === 'std' ? 'STD (right turns)' : 'Non-STD (left turns)'}, inbound ${fmt(I)}°, outbound ${fmt(O)}°`,
    turn === 'std'
      ? `d = track to fix − inbound = ${fmt(trk)} − ${fmt(I)} = ${d}° (mod 360)`
      : `d = inbound − track to fix = ${fmt(I)} − ${fmt(trk)} = ${d}° (mod 360)`,
    `Sectors: direct 0–70 & 290–360, special direct 70–110, teardrop 110–180, parallel 180–290`,
  ];
  const zone = EITHER.find((e) => Math.abs(d - e.at) <= 5);
  if (zone) {
    steps.push(`d is within ±5° of the ${zone.at}° boundary → either ${ENTRY_NAME[zone.pair[0]]} or ${ENTRY_NAME[zone.pair[1]]}`);
    return { kind: 'hold', entry: null, either: zone.pair, turn, initial: null, trk: norm(trk), outbound: O, steps };
  }
  const initial = entryInitial(entry, { inbound: I, turn, trk });
  steps.push(`d = ${d}° → ${ENTRY_NAME[entry]}`);
  if (entry === 'teardrop') steps.push(`Teardrop track = ${fmt(O)} ${turn === 'std' ? '−' : '+'} 30 = ${fmt(initial)}°`);
  if (entry === 'parallel') steps.push(`Parallel: fly outbound track ${fmt(O)}° on the non-holding side`);
  if (entry === 'direct') steps.push(`Direct: turn ${turn === 'std' ? 'right' : 'left'} to outbound ${fmt(O)}°`);
  if (entry === 'special') steps.push(`Special direct: hold ${fmt(trk)}° for 15 s, turn ${turn === 'std' ? 'right' : 'left'} to ${fmt(O)}°, outbound 45 s`);
  return { kind: 'hold', entry, either: null, turn, initial, trk: norm(trk), outbound: O, steps };
}

export function holdText({ entry, either, turn, initial, trk, outbound }) {
  if (either) return `Either ${ENTRY_NAME[either[0]]} or ${ENTRY_NAME[either[1]]}`;
  const dirWord = turn === 'std' ? 'right' : 'left';
  if (entry === 'direct') return `Direct, turn ${dirWord} to TRK ${fmt(initial)}°`;
  if (entry === 'special') return `Special direct, hold ${fmt(trk)}° for 15 s, then turn ${dirWord} to TRK ${fmt(outbound)}°`;
  return `${ENTRY_NAME[entry]}, initial track ${fmt(initial)}°`;
}
```

Notes:
- The sector boundaries are from the course slide. Non-STD is computed by mirroring `d`.
- The "either" zones exist only at 110, 180 and 290; 70 is a company-internal boundary.

```js
// Scenarios, questions and distractors. Pure: all randomness comes from `rng`.
import {
  norm, sdiff, fmt, interception, interceptText, holding, holdText,
  ENTRIES, EITHER_PAIRS, entryInitial,
} from './rules.js';

export function mulberry32(seed) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

const int = (rng, lo, hi) => lo + Math.floor(rng() * (hi - lo + 1)); // inclusive
const pick = (rng, arr) => arr[Math.floor(rng() * arr.length)];
function shuffle(rng, arr) {
  const a = [...arr];
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}

// |Δ| ranges per band, keeping 2° away from 15/30/70 and away from 0/180.
export const BANDS = {
  correction: [2, 12],
  '45': [17, 28],
  '90/45': [32, 68],
  overstation: [72, 175],
};

// settings: { types: ['intercept','hold'], display: 'numbers'|'instruments'|'mixed', instruments: ['rmi','hsi','dicdi'] }
export function makeScenario(rng, settings, id) {
  const kind = pick(rng, settings.types);
  const display = pickDisplay(rng, settings);
  const flag = pick(rng, ['TO', 'FROM']);
  if (kind === 'intercept') {
    const dir = pick(rng, ['inbound', 'outbound']);
    const band = pick(rng, dir === 'inbound' ? ['correction', '45', '90/45'] : Object.keys(BANDS));
    const [lo, hi] = BANDS[band];
    const radial = int(rng, 0, 359);
    const pos = norm(radial + (rng() < 0.5 ? -1 : 1) * int(rng, lo, hi));
    return {
      id, kind, display, flag, radial, dir, pos,
      phrasing: pick(rng, ['radial', 'q']),
      dist: int(rng, 30, 120) / 10,
      hdg: int(rng, 0, 359),
      gs: pick(rng, [90, 100, 110, 120, 140]),
    };
  }
  const inbound = int(rng, 0, 359);
  const turn = pick(rng, ['std', 'nonstd']);
  // ~20% land in a ±5° either zone.
  const d = rng() < 0.2 ? pick(rng, [110, 180, 290]) + int(rng, -5, 5) : int(rng, 0, 359);
  const trk = turn === 'std' ? norm(inbound + d) : norm(inbound - d);
  return {
    id, kind, display, flag, inbound, turn, trk,
    nav: pick(rng, ['NDB', 'VOR']),
    hdg: norm(trk + int(rng, -40, 40)),
  };
}

function pickDisplay(rng, { display, instruments }) {
  if (display === 'numbers' || instruments.length === 0) return 'numbers';
  if (display === 'instruments') return pick(rng, instruments);
  return pick(rng, ['numbers', ...instruments]);
}

export function solve(s) {
  return s.kind === 'intercept'
    ? interception({ radial: s.radial, dir: s.dir, pos: s.pos })
    : holding({ inbound: s.inbound, turn: s.turn, trk: s.trk });
}

// ---------- question text ----------

export function promptText(s) {
  if (s.kind === 'intercept') {
    const target = s.phrasing === 'q'
      ? (s.dir === 'inbound' ? `QDM ${fmt(s.radial + 180)}°` : `QDR ${fmt(s.radial)}°`)
      : `radial ${fmt(s.radial)}° flying ${s.dir}`;
    const where = s.display === 'numbers'
      ? (s.phrasing === 'q' ? `Your QDM is ${fmt(s.pos + 180)}°, ` : `You are on radial ${fmt(s.pos)}°, `)
      : 'You are at the position shown, ';
    return `${where}${s.dist.toFixed(1)} NM from the station, HDG ${fmt(s.hdg)}°, GS ${s.gs} kt. ` +
      `You have to intercept ${target}. What is the type of interception, initial track and interception track? (No wind)`;
  }
  const where = s.display === 'numbers' ? ` Your track to the ${s.nav} is ${fmt(s.trk)}°.` : '';
  return `You have to join a ${s.turn === 'std' ? 'STD' : 'Non-STD'} holding over the ${s.nav}, inbound track ${fmt(s.inbound)}°.` +
    `${where} What is your entry type and initial track?`;
}

// ---------- distractors ----------

function interceptPool(s, correct) {
  const P = s.pos;
  const pool = [];
  const add = (text, mistake) => pool.push({ text, mistake });
  const T = s.dir === 'inbound' ? norm(s.radial + 180) : s.radial;
  const k0 = Math.sign(sdiff(T, correct.intercept)) || 1; // side the correct answer turns to
  const a = Math.abs(sdiff(s.radial, P));
  const corrAngle = Math.min(2 * a, 30);
  const offs = { correction: [corrAngle, corrAngle], '45': [45, 45], '90/45': [90, 45] };
  for (const base of [T, norm(T + 180)]) {
    for (const k of [k0, -k0]) {
      for (const type of ['correction', '45', '90/45']) {
        const [i, x] = offs[type];
        const opt = { type, initial: norm(base + k * i), intercept: norm(base + k * x) };
        const m = [];
        if (base !== T) m.push('reciprocal (radial ↔ QDM mix-up)');
        if (k !== k0 && correct.type !== 'overstation') m.push('wrong side of the radial');
        if (type !== correct.type) m.push('wrong interception type');
        add(interceptText(opt), m.join(', ') || 'wrong side of the radial');
      }
    }
  }
  if (correct.type === 'correction') {
    const t = norm(T + k0 * a);
    add(interceptText({ type: 'correction', initial: t, intercept: t }), 'correction angle not doubled');
  }
  if (correct.type === 'overstation') {
    const wrong = norm(2 * s.radial - correct.intercept);
    add(interceptText({ ...correct, intercept: wrong }), 'over-station interception on the wrong side');
  }
  if (s.display !== 'numbers') {
    const flipped = { ...s, pos: norm(P + 180) };
    try {
      add(interceptText(solve(flipped)), 'TO/FROM (needle head/tail) read backwards');
    } catch { /* flipped position is out of scope for inbound; skip */ }
  }
  return pool;
}

function holdPool(s, correct) {
  const pool = [];
  const add = (text, mistake) => pool.push({ text, mistake });
  const O = norm(s.inbound + 180);
  if (correct.entry === 'teardrop') {
    add(holdText({ ...correct, initial: norm(s.turn === 'std' ? O + 30 : O - 30) }), 'teardrop on the wrong side');
  }
  for (const turn of ['std', 'nonstd']) {
    const mirrored = turn !== s.turn;
    const h = holding({ inbound: s.inbound, turn, trk: s.trk });
    if (mirrored) add(holdText(h), 'STD / Non-STD mirrored');
    for (const entry of ENTRIES) {
      const initial = entryInitial(entry, { inbound: s.inbound, turn, trk: s.trk });
      const m = [];
      if (entry !== correct.entry) m.push('wrong sector');
      if (mirrored) m.push('STD / Non-STD mirrored');
      add(holdText({ entry, turn, initial, trk: s.trk, outbound: O }), m.join(', ') || 'wrong sector');
    }
  }
  if (s.display !== 'numbers') {
    add(holdText(holding({ inbound: s.inbound, turn: s.turn, trk: norm(s.trk + 180) })), 'TO/FROM (needle head/tail) read backwards');
  }
  for (const pair of EITHER_PAIRS) add(holdText({ either: pair }), correct.either ? 'wrong boundary' : 'not near a sector boundary (±5°)');
  return pool;
}

// Build a multiple-choice question from a scenario. Options are shuffled by `rng`.
export function buildQuestion(s, rng) {
  const result = solve(s);
  const correctText = result.kind === 'intercept' ? interceptText(result) : holdText(result);
  const pool = result.kind === 'intercept' ? interceptPool(s, result) : holdPool(s, result);
  const seen = new Set([correctText]);
  const distinct = [];
  for (const o of pool) {
    if (seen.has(o.text)) continue;
    seen.add(o.text);
    distinct.push(o);
  }
  // Single-mistake options first (most instructive), then the rest, randomised within each group.
  const single = shuffle(rng, distinct.filter((o) => !o.mistake.includes(',')));
  const multi = shuffle(rng, distinct.filter((o) => o.mistake.includes(',')));
  const distractors = [...single, ...multi].slice(0, 4);
  const options = shuffle(rng, [{ text: correctText, mistake: null }, ...distractors]);
  return {
    scenario: s,
    prompt: promptText(s),
    options,
    correctIndex: options.findIndex((o) => o.mistake === null),
    steps: [...readingSteps(s), ...result.steps],
    statKey: result.kind === 'intercept' ? result.type : 'holding',
  };
}

// What the instruments show for a scenario. P = your radial.
export function instrumentState(s) {
  const P = s.kind === 'intercept' ? s.pos : norm(s.trk + 180);
  const qdm = norm(P + 180);
  return { P, hdg: s.hdg, qdm, obs: s.flag === 'FROM' ? P : qdm, flag: s.flag, nav: s.kind === 'hold' ? s.nav : 'VOR' };
}

// First worked step in instrument modes: what the instrument says.
export function readingSteps(s) {
  if (s.display === 'numbers') return [];
  const { P, qdm, obs } = instrumentState(s);
  if (s.display === 'rmi') {
    return [`RMI: heading ${fmt(s.hdg)}°, needle head QDM ${fmt(qdm)}°, tail QDR ${fmt(P)}° → you are on R-${fmt(P)}`];
  }
  const what = s.display === 'hsi' ? 'HSI' : 'CDI';
  return [s.flag === 'FROM'
    ? `${what}: course ${fmt(obs)}° centred with FROM flag → you are on R-${fmt(P)}, heading ${fmt(s.hdg)}°`
    : `${what}: course ${fmt(obs)}° centred with TO flag → QDM ${fmt(obs)}°, you are on R-${fmt(P)}, heading ${fmt(s.hdg)}°`];
}
```

Notes:
- **Interception pool:** every combination of {required track, its reciprocal} × {correct side, other side} × {correction, 45, 90/45}. Each one is labelled with the mistakes it encodes. Single-mistake options are preferred.
- **Holding pool:** every entry under both STD and Non-STD, plus the three "either" pairs, plus the special cases (teardrop on the wrong side, flag read backwards).
- The pools are always larger than 4 distinct texts, so every question has 4–5 options. The 10,000-question test enforces this.

```js
// localStorage persistence. Every access is guarded: the app must work without storage.
const KEY = 'basicir.v1';

export const defaults = () => ({
  version: 1,
  settings: { types: ['intercept', 'hold'], display: 'numbers', instruments: ['rmi'], timer: 45, length: 20 },
  stats: {}, // statKey → { correct, total, ms }
  mistakes: [], // scenarios
});

const storageOr = (storage) => storage ?? globalThis.localStorage;

export function load(storage) {
  try {
    const d = JSON.parse(storageOr(storage).getItem(KEY));
    if (d && d.version === 1) {
      const def = defaults();
      return { ...def, ...d, settings: { ...def.settings, ...d.settings } };
    }
  } catch { /* blocked or corrupt → defaults */ }
  return defaults();
}

export function save(data, storage) {
  try { storageOr(storage).setItem(KEY, JSON.stringify(data)); } catch { /* not persisted */ }
}

// Record one answered question. Returns the updated data (mutates in place).
export function record(data, { statKey, correct, ms, scenario }) {
  const st = (data.stats[statKey] ??= { correct: 0, total: 0, ms: 0 });
  st.total++;
  st.ms += ms;
  if (correct) st.correct++;
  const i = data.mistakes.findIndex((m) => m.id === scenario.id);
  if (!correct && i === -1) data.mistakes.push(scenario);
  if (correct && i !== -1) data.mistakes.splice(i, 1);
  return data;
}
```

- [ ] **Step 2: Create `app.js`**

```js
import { mulberry32, makeScenario, buildQuestion } from './generator.js';
import { renderInstrument } from './instruments/index.js';
import { load, save, record } from './store.js';

const $ = (id) => document.getElementById(id);
const form = $('setup');
const LABEL = { correction: 'Correction', '45': '45° intercept', '90/45': '90°/45° intercept', overstation: 'Over station', holding: 'Holding' };

const data = load();
let session = null; // { rng, review, queue, i, n, log: [], q, startedAt, deadline, answered }

// ---------- setup ----------

function fillSetup() {
  const s = data.settings;
  form.querySelectorAll('[name=types]').forEach((el) => (el.checked = s.types.includes(el.value)));
  form.querySelectorAll('[name=instruments]').forEach((el) => (el.checked = s.instruments.includes(el.value)));
  form.querySelectorAll('[name=display]').forEach((el) => (el.checked = el.value === s.display));
  form.querySelectorAll('[name=length]').forEach((el) => (el.checked = Number(el.value) === s.length));
  form.querySelectorAll('[name=timerPreset]').forEach((el) => (el.checked = Number(el.value) === s.timer));
  form.querySelector('[name=timer]').value = s.timer;
  $('review').textContent = `Review mistakes (${data.mistakes.length})`;
  $('review').disabled = data.mistakes.length === 0;
}

function readSetup() {
  const checked = (name) => [...form.querySelectorAll(`[name=${name}]:checked`)].map((el) => el.value);
  const timer = Math.max(0, Math.min(600, Number(form.querySelector('[name=timer]').value) || 0));
  data.settings = {
    types: checked('types'),
    instruments: checked('instruments'),
    display: checked('display')[0] ?? 'numbers',
    length: Number(checked('length')[0] ?? 20),
    timer,
  };
  save(data);
}

form.addEventListener('change', (e) => {
  if (e.target.name === 'timerPreset') form.querySelector('[name=timer]').value = e.target.value;
  if (e.target.name === 'timer') form.querySelectorAll('[name=timerPreset]').forEach((el) => (el.checked = el.value === e.target.value));
  readSetup();
});

function setupError() {
  const s = data.settings;
  if (s.types.length === 0) return 'Pick at least one exercise.';
  if (s.display !== 'numbers' && s.instruments.length === 0) return 'Pick at least one instrument, or switch to Numbers.';
  return '';
}

function show(id) {
  for (const sec of ['setup', 'quiz', 'end']) $(sec).hidden = sec !== id;
}

// ---------- session ----------

function start(review) {
  readSetup();
  const err = review ? '' : setupError();
  $('setupError').hidden = !err;
  $('setupError').textContent = err;
  if (err) return;
  const seed = Date.now() >>> 0;
  const queue = review ? [...data.mistakes] : null;
  session = { seed, rng: mulberry32(seed), review, queue, i: 0, n: review ? queue.length : data.settings.length, log: [] };
  show('quiz');
  nextQuestion();
}

function nextQuestion() {
  if (session.n && session.i >= session.n) return endSession();
  const s = session.review
    ? session.queue[session.i]
    : makeScenario(session.rng, data.settings, `${session.seed}-${session.i}`);
  const q = buildQuestion(s, session.rng);
  session.q = q;
  session.answered = false;
  session.i++;

  $('progress').textContent = session.n ? `${session.i} / ${session.n}` : `#${session.i}`;
  $('prompt').textContent = q.prompt;
  $('instrument').innerHTML = renderInstrument(s);
  $('feedback').hidden = true;
  const opts = $('options');
  opts.innerHTML = '';
  q.options.forEach((o, idx) => {
    const b = document.createElement('button');
    b.className = 'opt';
    b.textContent = `${idx + 1} · ${o.text}`;
    b.addEventListener('click', () => answer(idx));
    opts.append(b);
  });

  session.startedAt = performance.now();
  session.deadline = data.settings.timer ? session.startedAt + data.settings.timer * 1000 : null;
  tick();
}

function tick() {
  if (!session || session.answered) return;
  if (session.deadline === null) {
    $('clock').textContent = '';
    $('timebar').style.width = '0%';
    return;
  }
  const left = session.deadline - performance.now();
  if (left <= 0) return answer(null);
  $('clock').textContent = `⏱ ${Math.ceil(left / 1000)} s`;
  $('timebar').style.width = `${(left / (data.settings.timer * 1000)) * 100}%`;
  requestAnimationFrame(tick);
}

function answer(idx) {
  if (session.answered) return;
  session.answered = true;
  const q = session.q;
  const ms = Math.round(performance.now() - session.startedAt);
  const correct = idx === q.correctIndex;
  record(data, { statKey: q.statKey, correct, ms, scenario: q.scenario });
  save(data);
  session.log.push({ statKey: q.statKey, correct, ms, mistake: idx === null ? 'ran out of time' : q.options[idx].mistake });

  [...$('options').children].forEach((b, i) => {
    b.disabled = true;
    if (i === q.correctIndex) b.classList.add('correct');
    if (i === idx && !correct) b.classList.add('wrong');
  });
  const v = $('verdict');
  v.className = `verdict ${correct ? 'ok' : 'bad'}`;
  v.textContent = correct
    ? `✓ Correct (${(ms / 1000).toFixed(1)} s)`
    : idx === null
      ? '✗ Time is up'
      : `✗ ${q.options[idx].mistake}`;
  $('steps').innerHTML = '';
  for (const step of q.steps) {
    const li = document.createElement('li');
    li.textContent = step;
    $('steps').append(li);
  }
  $('feedback').hidden = false;
  $('next').focus();
}

function endSession() {
  const log = session.log;
  session = null;
  const right = log.filter((l) => l.correct).length;
  const avg = log.length ? log.reduce((a, l) => a + l.ms, 0) / log.length / 1000 : 0;
  $('score').textContent = `Score ${right} / ${log.length} · average ${avg.toFixed(1)} s`;

  const per = {};
  for (const l of log) {
    per[l.statKey] ??= { correct: 0, total: 0 };
    per[l.statKey].total++;
    if (l.correct) per[l.statKey].correct++;
  }
  $('breakdown').innerHTML = Object.entries(per)
    .map(([k, v]) => `<tr><td>${LABEL[k]}</td><td>${v.correct} / ${v.total}</td></tr>`).join('');

  const counts = {};
  for (const l of log) if (!l.correct) counts[l.mistake] = (counts[l.mistake] ?? 0) + 1;
  const top = Object.entries(counts).sort((a, b) => b[1] - a[1])[0];
  $('topMistake').textContent = top ? `Most common mistake: ${top[0]} (×${top[1]})` : 'No mistakes 🎉';

  $('alltime').innerHTML = Object.entries(data.stats)
    .map(([k, v]) => `<tr><td>${LABEL[k]}</td><td>${Math.round((100 * v.correct) / v.total)}% of ${v.total} · ${(v.ms / v.total / 1000).toFixed(1)} s</td></tr>`).join('');
  show('end');
}

// ---------- wiring ----------

$('start').addEventListener('click', () => start(false));
$('review').addEventListener('click', () => start(true));
$('next').addEventListener('click', nextQuestion);
$('finish').addEventListener('click', () => (session.log.length ? endSession() : (session = null, fillSetup(), show('setup'))));
$('again').addEventListener('click', () => { fillSetup(); show('setup'); });

document.addEventListener('keydown', (e) => {
  if (!session || $('quiz').hidden) return;
  if (!session.answered && /^[1-5]$/.test(e.key)) {
    const idx = Number(e.key) - 1;
    if (idx < session.q.options.length) answer(idx);
  } else if (session.answered && e.key === 'Enter') {
    e.preventDefault();
    nextQuestion();
  }
});

fillSetup();
```

Notes:
- The timer uses a `performance.now()` deadline checked on every animation frame, so a throttled background tab can't stretch it.
- The document-level Enter handler calls `preventDefault()` so the focused Next button doesn't advance twice.
- Review mode iterates over a *copy* of `data.mistakes`, because `record()` removes items as you answer them correctly.
